# Aether

跨平台智能語音控制 App。透過藍牙裝置與語音指令，控制電腦、平板、手機，並驅動 AI 代理自動完成預先安排的工作。

## 功能

- 語音輸入與指令辨識（支援繁體中文）
- 藍牙裝置管理（支援 Web Bluetooth 的瀏覽器可真實配對）
- AI 代理設定與語音觸發
- 功能開關自訂（語音打字、系統控制、Email、AI 代理）
- PWA 支援，可安裝到主畫面變成獨立 App
- 設定自動儲存在本地

## 支援平台

只要有現代瀏覽器即可使用：

- iOS / Android（Safari、Chrome）
- Windows / macOS（Chrome、Edge）
- 可「加入主畫面」或安裝為獨立應用程式

## 快速開始

1. 下載或 Clone 這個倉庫
2. 用瀏覽器開啟 `index.html`
3. 點擊中央麥克風按鈕開始說話
4. 在底部導航切換裝置、代理、設定頁面

建議使用 Chrome / Edge / Safari 以獲得最佳語音辨識與藍牙支援。

## 安裝為 App

在手機瀏覽器開啟後：

- iOS：分享 → 加入主畫面
- Android：選單 → 加入主畫面 / 安裝應用程式

桌面版也可在瀏覽器選單中選擇「安裝 Aether」。

## 技術

純 HTML + CSS + JavaScript，無需建置工具或額外依賴。
